
# FlowTrack - Manufacturing Execution System 🏭
A dual-interface Apparel MES designed to streamline factory operations, bridging the gap between high-level production planning and individual worker execution.

## 🚀 Features
- **Dashboard:** iOS-style animated dashboard with live charts.
- **Batch Management:** Create, track, and complete manufacturing batches.
- **Quality Control:** AQL grading system with defect tracking.
- **Rework Bay:** Manage defective items (Fix/Scrap logic).
- **Worker Management:** Track worker efficiency and assignments.

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS (iOS Design System), JavaScript, SweetAlert2, Chart.js.
- **Backend:** PHP (Native).
- **Database:** MySQL.

## 💻 How to Run
1. Download the repository.
2. Move the folder to `xampp/htdocs`.
3. Import `flowtrack_mes.sql` into phpMyAdmin.
4. Configure database connection in `layout_top.php` (if applicable).
5. Open `http://localhost/flowtrack_mes` in your browser.
